# 十八維等角直線論文的第二次正確性審查

2026 年 11 月 24 日。修訂稿主張任意共同角度下的最大數為 57。上界依賴第 3 節的正根秩排除、第 4 節的帶標記嵌入，以及第 5、6 節對全部宿主的處理。第 2 節證明角度歸約，第 7 節給出可精確核驗的下界構造。

## 修正與補證

| 位置 | 發現與處理 |
| --- | --- |
| 第 3 節，候選根 | 飽和性只保證有原向量 v 使 (s,v) 不屬於 2ℤ。候選 s 尚未證明和所有原向量整配對。A₁³A₇² 的例子給出 5/2。因為 (s+v)²=9+2(s,v)，判定是否屬於 1+4ℤ 即可。原程式正是這個檢查。 |
| 第 3 節，中秩全集 | 從所有 1,794 個秩 6 至 15 的 ADE 型重建分類，驗算了 8,001 個整數切面。剩餘 1,097 型中有十個純 A₁ 型、七個不可約型、兩個秩六混合型分別由附錄、軌道界和能量界排除。其餘恰為後段接收的 1,078 型。 |
| 第 3 節，資料傳遞 | 秩 16 初始共 815 型、12,055 個正殘錨、142,334 筆面積平方類紀錄。切割後的 4,111 筆逐層核對實際標記，最後 21 筆在兩份終端資料逐一一致。故意代換一個標記、保留數量的測試被拒絕。另驗算秩 17、18 起始資料。 |
| 第 3 節，帶標號支撐 | 五個固定碼域共走訪 448,842 個相容子集，留下 11,584 個帶標號支撐。兩套產生法最後五份排序清單逐位元組一致。另枚舉所有保碼的帶號座標置換，逐筆對照 11,584 筆支撐所屬的軌，分別得到 134、1、1、0、5 軌。其後 141 個支撐軌中有 15 個進入重數計算，合計測 421 個重數選擇。 |
| 第 4 節，判別形式 | 將奇素數部分寫成明確的分子映射。二進判別長度達三時，證明有奇半整數值的非退化二階直和因子，符合 Nikulin 等秩情形。另枚舉秩三與秩四所有初等二群二次形式，作為邊界檢查。 |
| 第 6 節，宿主 | 無根條件作用在中心化方向 2x−w 的有理張成空間。獨立生成四種例外宿主的形狀域，逐一核對 216 筆標記。A₅⁴D₄ 在擴大的保標記群下，兩組 131、35 個搜尋軌併為 60、20 個。證書仍使用原有標記以便對照。 |
| 第 6 節，二元終局 | 由 A₂¹² 和 A₄⁶ 的奇倍座標重新生成七份輸入。全候選集二秩皆為 21，假想選集的二秩最多 18。原刪除計數器處理這批新輸入，在七個情形均沒有可容 58 軸的合格法向對。 |
| 附錄 A，純 A₁¹¹ | 245 個軌保留指定的滿匹配。解除此標記後為 172 軌，其中 162 軌由二秩排除。其餘十軌的 1,600 個符號選擇經模 101 與延伸檢查後，此支最多 53 條線。 |
| 引言與文獻 | 說明 Degtyarev 的平方四殼模型、配對和 Elkies 在該模型中的相對界，以及較長預印本在個別宿主上的既有上界。本文另給任意假想 58 線到正交 A₂ 標記的歸約。 |

## 重播

從外層壓縮檔解開後，在含 README.md 的目錄用 Python 3.11 以上解開內附的 EL18_58_Search_Checkpoint.zip。以下兩個命令的起點不同。

```sh
(cd EL18_58_search && python3 -B joint23/replay.py --full --manifest)
python3 -B audit/revision2/replay.py EL18_58_search
```

上層 README 列出了執行環境。請保持 Python 斷言啟用。本輪從發行的 ZIP 另行解開後，第一個命令核對 585 個清單項目，完整記錄見 full.log。第二個命令逐筆比對輸出，並比對兩套實作生成的五份完整支撐清單及五份軌代表映射。各檢查對應同名程式與 .out 檔，彙總見 replay.out。全程不需要隨機種子。

兩套支撐演算法共用五個固定碼域作為輸入，七個重建的二元終局共用一個刪除計數器。其餘原有歷史排除由第 23 版完整重播核驗。本次審查沒有將所有原有程式逐一獨立重寫。外部使用的 Niemeier 分類、Nikulin 存在定理和長度 24 的 Type II 碼分類列於正文書目。這份報告記錄工作稿的內部審查。
