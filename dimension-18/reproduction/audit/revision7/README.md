# One rank test for all fifteen terminal markings

From the package root, extract EL18_58_Search_Checkpoint.zip alongside the audit directory. With Python 3.11 or newer, NumPy and a C++17 compiler, run this directory's replay.py with the path to the extracted EL18_58_search directory. Add --second to rebuild the cell partitions and compatibility edges from coordinates and the binary kernel from an integer row basis. It also runs the optional Walsh count on the same candidate sets. Both commands rebuild all input files in a temporary directory. The calculation is deterministic and uses no seed.

The proof uses the 216 list partitions already checked in revision6. The generator reads all 216 and selects precisely the markings for which the number of lists is at least 116. For each such marking it regenerates the complete marked norm-four shell using revision6/verify_chains.py, the coset data and the representative w from revision2/exceptional_shells.py, and retains its points x with (w,x)=3. Identify x with w-x and keep all resulting axes, including those that could be discarded by a single-axis cone test. The row y is a common integer multiple of 2x-w.

The implemented cone uses only successive coordinate differences within a block of free equal coordinates of w in an A factor. The first three positions of a marked A factor, and all of the marked D factor, are held fixed. Block sums test membership in the root span. Initial partial sums are precisely the coefficients in the successive difference basis. If y+y' or y-y' lies in the nonzero positive or negative cone, its two endpoints cannot both have height zero. Edges with forbidden absolute inner product determine connected components. Within each component, only edges passing both that angle condition and the cone test are allowed. The sum of the clique numbers inside the components bounds any simultaneous selection. Any omitted cross-component restrictions can only raise the upper bound.

The routine normal_sieve/pack.py in the checkpoint first keeps rationally independent columns spanning the columns of the integer matrix of directions. When a nonempty subset of columns sums to an even column, replace one member by half the sum. This operation is invertible over the rationals, preserves integrality, and halves the absolute value of each fixed nonzero full-column minor. It therefore terminates at full binary column rank. The binary rank of the selected rows is at most their rational rank. The 288-axis records of A3 with indices 0 and 1 have rank 20. Every other record has rank 21.

The direct verifier is normal_sieve/audit/independent.cpp. It computes the number of axes and the clique-sum bound in the zero section of every nonzero binary equation. For a putative selection of 58, average deletion counts over a common space of k=d-18 independent normal directions and again inside the first equation's zero section. This proves that at least one eligible pair of independent equations must occur. Check all such pairs on their exact intersection. The clique recurrence omits the first vertex or takes it and restricts to its neighbors; it gives zero on an empty section, including in a component with no surviving axis. The counting and averaging arguments still include every axis, including any that ultimately contribute zero to a chosen section.

All fifteen records have zero successful two-equation tests. Some first choices yield the same plane. The number of tests is a count of operations over labelled records. The optional second verifier reuses the candidate matrices and graphs, evaluates point counts by a Walsh transform, uses another clique recursion, and chooses preferred first normals. Its number of tests may consequently be smaller. The standalone chapter in the paper gives the inequalities for the first and second choices.
